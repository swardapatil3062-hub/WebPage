# 🏥 Hospital Management System

A simple and attractive **Hospital Management System website** built using HTML, CSS, and JavaScript. It helps manage hospital information through a user-friendly dashboard.

## ✨ Features

- 📊 **Dashboard** – View hospital statistics.
- 🧑‍⚕️ **Doctor Management** – Add, edit, delete, and search doctor records.
- 🧑‍🤝‍🧑 **Patient Management** – Manage patient details.
- 📅 **Appointment Management** – Organize appointments.
- 🏢 **Department Management** – Manage hospital departments.
- 💳 **Billing Management** – Manage billing records.
- 🔍 **Search Functionality** – Find records easily.
- 🎨 **Attractive UI** – Modern design with healthcare images and responsive layouts.
- 💾 **Local Storage** – Store records in the browser without a database.

## 🛠️ Technologies Used

- **HTML5** – Website structure
- **CSS3** – Styling and responsive design
- **JavaScript** – Functionality and record management
- **Browser Local Storage** – Saving data locally

## 🚀 How to Run the Project

1. Download or clone this repository.
2. Open the project folder.
3. Locate the `attractive_hospital_management_system.html` file.
4. Double-click the HTML file or open it using Google Chrome.
5. Start managing hospital records.

No database installation or server setup is required.

## 💻 How to Use

1. Open the website in your browser.
2. Navigate through the dashboard sections.
3. Add new patients, doctors, appointments, departments, or billing records.
4. Edit, delete, and search records as needed.

## 💾 Data Storage

This project uses browser Local Storage instead of a database. Records are stored in the browser on the device where the website is used. Clearing browser data or using a different browser may affect access to saved records.

**Note:** This is a learning/demo project. Do not enter real confidential patient information.

## 🎯 Project Objective

The objective of this project is to create a simple, attractive, and easy-to-use website for managing basic hospital operations and learning front-end web development.
